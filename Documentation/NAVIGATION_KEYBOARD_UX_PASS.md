# Navigation + Keyboard UX Pass

Changes in this pass:

- The custom bottom tab bar is hidden while a tool/detail screen is pushed from Home or Tools.
- The tab bar returns automatically when the user navigates back to a root tab.
- Reference Data also hides the custom tab bar while open.
- Unit Converter, Duty/VAT Calculator, and HS Search now dismiss the keyboard when the user taps outside text inputs.
- Interactive scroll-to-dismiss keyboard behavior is enabled on those input-heavy screens.
- Tapping directly inside a text field does not trigger the background keyboard-dismiss gesture.
- Fixed the creator-credit row to use existing design-system-compatible spacing/accent values.
