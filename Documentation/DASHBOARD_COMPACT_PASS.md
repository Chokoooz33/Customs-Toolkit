# Dashboard Compact Pass

Changes applied to the Version 3.2 dashboard after on-device visual review:

- Reduced the brand/identity hero footprint (smaller mark, tighter type, padding, radius, and shadow).
- Removed the reference status / tariff record / recent-search metric card from Home; reference-data details remain available elsewhere in the product.
- Tightened vertical spacing so quick tools appear sooner.
- Lowered and slightly slimmed the custom bottom navigation bar so it sits closer to the iPhone home-indicator region without covering it.
- Set the TabView background to the grouped app background to eliminate the bright/white-looking safe-area plate beneath the custom tab bar.
- No tariff, calculator, gold-price, or other business logic changed.
