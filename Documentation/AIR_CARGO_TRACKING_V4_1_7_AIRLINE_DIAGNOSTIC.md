# Air Cargo Tracking V4.1.7 — Airline Adapter Diagnostic

This build does not change the validated Oman Air or Transom flows.
For non-Oman airline pages it logs the rendered inputs, candidate actions, forms, iframe boundaries,
selected field/action, and page sample. The purpose is to replace the current generic adaptive
heuristic with deterministic per-carrier adapters one carrier at a time using a real AWB.
