# Duty Calculator V4.2.3 — Simplified Result

Scope: result-card UX only. Calculation formulas, HS logic, currencies, Air/Sea routing, permit flow and tracking are unchanged.

Primary result card now shows only:
- Customs duty amount
- VAT amount
- Total duty + VAT
- Documentation Guarantee (2%) only when applicable
- Bayan Documentation fee
- Final Total

CIF, customs duty rate, VAT taxable base and VAT rate remain in the calculation model but are hidden from the primary result card to reduce visual noise.
