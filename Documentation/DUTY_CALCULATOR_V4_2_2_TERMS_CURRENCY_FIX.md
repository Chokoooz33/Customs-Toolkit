# Duty Calculator V4.2.2 — Terms + Currency Fix

- Makes CIF / CFR / FOB / EXW permanently visible with the app segmented control.
- Fixes the misleading foreign-currency exchange-rate placeholder: USD/AED receive an editable suggested rate; EUR/GBP require an explicit customs rate.
- Makes the exchange-rate field explicit as `1 CUR = X OMR` and highlights a missing rate instead of silently producing no result.
- Accepts Arabic/Persian digits and decimal separators in amount/rate fields.
- No Air Cargo Tracking, Transom, Emirates or Cargo Board behavior changed.
